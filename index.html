🎮 CONTROLES META QUEST
🎯 GRIP IZQUIERDO/DERECHO
→ Agarrar y mover objeto
→ Con rotación de muñeca: rotar objeto

📏 AMBOS GRIPS (mismo objeto)
→ Escalar separando/juntando manos

🔘 TRIGGER
→ Seleccionar objetos/elementos
→ Ray visual para apuntar

🅰️ BOTÓN A/X
→ Cambiar modo (Object/Vertex/Edge/Face)

🅱️ BOTÓN B/Y
→ Abrir/Cerrar UI de edición flotante
→ (Si UI abierta: cambiar herramienta)

📱 UI FLOTANTE
→ Rotar mano 180° (palma arriba) o presionar B/Y
→ Panel de control completo con valores precisos
→ Se ancla a la mano que la activa

👍 JOYSTICK IZQUIERDO
→ Mover posición (adelante/atrás/lados)

👍 JOYSTICK DERECHO
→ Rotar vista (izquierda/derecha)

🔄 MENÚ QUEST
→ Botón Oculus para salir/ajustes
